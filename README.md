# 인연 찾기 (랜덤 매칭 + 타이머)

30명 정도가 접속해서, 관리자가 누르면 겹치지 않게 랜덤으로 짝을 지어주고
(짝의 이름은 견우/직녀, 선재/임솔 같은 캐릭터명으로만 보여줌 - 실제로 몇 번 기기와 매칭됐는지는 알 수 없음),
타이머도 관리자가 시간 조절해서 시작시킬 수 있는 앱입니다.

## 파일 구조
```
couple-match/
  server.js          # Socket.io 서버 (매칭/타이머 로직)
  package.json
  public/
    index.html        # 참가자 페이지
    admin.html         # 관리자 페이지
```

## 로컬에서 테스트하기
```bash
npm install
node server.js
```
그 다음 브라우저에서:
- 참가자: http://localhost:3000
- 관리자: http://localhost:3000/admin.html (기본 비밀번호: `admin1234`)

## 배포하기 (Render.com 예시 - 무료)
1. https://render.com 가입 후 "New Web Service" 선택
2. 이 폴더를 GitHub 저장소에 올리고 연결 (또는 zip 업로드 방식 지원 시 그대로 업로드)
3. Build Command: `npm install`
4. Start Command: `node server.js`
5. 환경변수(Environment)에 `ADMIN_PASSWORD` 를 원하는 비밀번호로 추가 (안 넣으면 기본값 `admin1234` 사용됨)
6. 배포되면 `https://프로젝트이름.onrender.com` 링크가 생김
   - 참가자용 링크: `https://프로젝트이름.onrender.com`
   - 관리자용 링크: `https://프로젝트이름.onrender.com/admin.html`

무료 티어는 15분 미사용 시 슬립 모드로 들어가니, 행사 시작 몇 분 전에 링크를 한 번 열어서 깨워두세요.

### Replit으로 배포하려면
1. Replit에서 "Create Repl" → Node.js 템플릿
2. 이 폴더의 파일들을 그대로 업로드
3. Secrets 탭에서 `ADMIN_PASSWORD` 추가 (선택)
4. Run 누르면 우측에 미리보기 URL이 생기고, "Deploy"로 항상 켜진 공개 링크도 만들 수 있음

## 캐릭터 쌍 수정하기
`server.js` 상단의 `CHARACTER_PAIRS` 배열에서 원하는 이름 쌍을 자유롭게 추가/삭제하세요.
```js
const CHARACTER_PAIRS = [
  ['견우', '직녀'],
  ['선재', '임솔'],
  // ...
];
```
매칭 인원이 캐릭터 쌍 개수보다 많으면 자동으로 재사용됩니다 (여러 쌍이 같은 이름을 받을 수 있음).

## 동작 방식 요약
1. 참가자가 링크로 접속하면 서버에 자동 등록되고, 모든 관리자 화면에 실시간으로 인원수가 반영됩니다.
2. 관리자가 **"매칭 시작"**을 누르면, 현재 대기 중인 인원들을 랜덤으로 1:1 매칭합니다.
   - 서버 내부적으로 어떤 기기끼리 매칭됐는지 기록해두고, 이후 라운드에서는 같은 기기끼리 다시 매칭되지 않도록 걸러냅니다.
   - 참가자에게는 캐릭터 이름만 보여주고, 상대방이 어떤 기기(누구)인지는 알려주지 않습니다.
3. 인원이 홀수라 한 명이 남으면 "대기 중" 상태로 표시되고 다음 라운드에 매칭됩니다.
4. 관리자가 **"다음 라운드로 초기화"**를 누르면 전원이 다시 대기 상태가 되어 새로 매칭할 수 있습니다.
5. 관리자가 분/초를 입력하고 **"타이머 시작"**을 누르면 모든 참가자 화면에 동시에 카운트다운이 표시됩니다.

## 보안 참고
- 관리자 비밀번호는 매우 단순한 방식입니다. 30명 규모의 소규모 행사용으로는 충분하지만,
  더 안전하게 쓰고 싶다면 `ADMIN_PASSWORD` 환경변수를 배포 시 반드시 변경하세요.
